# LambderI18n — Typed Translations

Standalone, framework-free, isomorphic translation module. Zero dependencies, no Node or DOM requirements (browser detection is feature-gated), so it is safe to import in lambda backends and frontend bundles alike.

```typescript
import { createLambderI18n } from "lambder";
```

## Concepts

- **Language registry** — every language the app can serve, with metadata (`name`, `englishName`, `intlLocale`, `dir`, plus any app extras). Declared once at init.
- **Enforced languages** — the subset every dictionary must always provide (typically `["en"]`). The `defaultLanguage` must be one of them.
- **Base dictionary** — app-wide general keys. Strict: every language must provide every key.
- **Extensions** — components add their own keys on top of the base, either strictly (`extend`: all languages required) or partially (`extendPartial`: only the enforced languages required, everything else optional and falling back).
- **Typed contract** — keys and `{token}` params are inferred from the `defaultLanguage` block at compile time. `t("greet")` is a compile error if `greet` is `"Hello {name}"`; `t("greet", { name: "Ada" })` is required.

## Setup

```typescript
// common/i18n.ts
export const i18n = createLambderI18n({
    languages: {
        en: { name: "English", englishName: "English", intlLocale: "en", dir: "ltr" },
        tr: { name: "Türkçe",  englishName: "Turkish", intlLocale: "tr", dir: "ltr" },
        ar: { name: "العربية", englishName: "Arabic",  intlLocale: "ar", dir: "rtl" },
    },
    defaultLanguage: "en",
    enforced: ["en"],
    base: {
        // The defaultLanguage block is the typed contract (keys + {token} params):
        en: { save: "Save", greet: "Hello {name}" },
        // base is strict — every language must provide every key:
        tr: { save: "Kaydet", greet: "Merhaba {name}" },
        ar: { save: "حفظ", greet: "مرحبا {name}" },
    },
    // Optional detector, tried before browser detection (return null to pass):
    detectLanguage: ({ isLanguageCode }) => {
        const fromPath = window.location.pathname.split("/")[1] ?? "";
        return isLanguageCode(fromPath) ? fromPath : null;
    },
});
```

## Translating

```typescript
i18n.t("save");                    // active language, resolved automatically
i18n.t("greet", { name: "Ada" });  // params compile-time enforced from {tokens}

const t = i18n.forLanguage("tr");  // explicitly bound (per-request backend use)
t("save");                          // "Kaydet"
```

### Language resolution (auto `t`)

Evaluated lazily, cached until it changes:

1. `setLanguage(code)` override (user preference, switcher)
2. `detectLanguage()` from setup — if provided and it returns a supported code
3. Browser detection — ordered `navigator.languages`, matching the full code (`zh-cn`) then the primary subtag (`de` from `de-AT`); skipped outside a browser
4. `defaultLanguage`

Missing translations fall back per key: active language → `defaultLanguage` → the key itself. `t` never throws.

## Extending in components

```typescript
// componentA.ts — strict: every language must provide every new key
const cI18n = i18n.extend({
    en: { compute: "Compute" },
    tr: { compute: "Hesapla" },
    ar: { compute: "احسب" },
});

// componentB.ts — partial: only the enforced languages are required
const bI18n = i18n.extendPartial({
    en: { upload: "Upload" },      // required (enforced)
    tr: { upload: "Yükle" },       // optional — ar falls back to en
});

bI18n.t("upload");   // extended key
bI18n.t("save");     // base keys remain visible — key space is merged
```

- Extensions return a **new instance**; the parent is untouched. Extensions chain (`extend` on an extended instance).
- All instances derived from the same root **share the active-language state**: `setLanguage` anywhere affects every translator instantly.
- Missing language blocks throw at creation time (and are compile errors first).

## Switching languages / reactivity

```typescript
i18n.setLanguage("tr");            // override (validate + notify listeners)
i18n.resetLanguage();              // clear override, re-run detection
i18n.currentLanguage;              // "tr"
i18n.currentLanguageMeta;          // { name: "Türkçe", intlLocale: "tr", dir: "ltr", ... }
const off = i18n.onLanguageChange((code) => { /* re-render */ });
```

The module is framework-free; a Vue adapter is a few lines:

```typescript
import { shallowRef } from "vue";
import { i18n } from "@common/i18n";

export const t = shallowRef(i18n.t);
i18n.onLanguageChange(() => { t.value = ((...args) => i18n.t(...args)) as typeof i18n.t; });

// Apply metadata to the document (RTL support):
i18n.onLanguageChange(() => {
    document.documentElement.lang = i18n.currentLanguage;
    document.documentElement.dir = i18n.currentLanguageMeta.dir ?? "ltr";
});
```

## Runtime dictionaries (fetched translations)

Dictionaries can be merged at runtime — e.g. locales fetched from an API instead of bundled. The compile-time contract still comes from the statically declared enforced blocks.

```typescript
const dict = await lambderCaller.api("public.getTranslations", { language: "tr" });
i18n.registerDictionary("tr", dict.translations);
```

Registrations on a parent are visible to all previously created extensions (lookup is layered, child-first).

## Backend usage

The active-language state is process-global, so on the backend prefer the explicit form — language is per-request:

```typescript
lambder.serveIndexHtml((ctx, res) => {
    const lang = pathLanguage(ctx.path);        // app logic
    const t = i18n.forLanguage(lang);
    return res.templateFile("index.html", { title: t("mainTitle") });
});
```

## API reference

| Member | Description |
|---|---|
| `createLambderI18n(config)` | Create the root instance. Config: `languages`, `defaultLanguage`, `enforced`, `base`, `detectLanguage?` |
| `t(key, params?)` | Translate in the auto-resolved language |
| `forLanguage(code)` | Translator bound to an explicit language |
| `extend(dict)` | Strict extension — all languages required |
| `extendPartial(dict)` | Partial extension — only enforced languages required |
| `registerDictionary(code, dict)` | Merge translations at runtime |
| `setLanguage(code)` / `resetLanguage()` | Override / re-detect the active language |
| `currentLanguage` / `currentLanguageMeta` | Active code / its metadata |
| `onLanguageChange(cb)` | Subscribe; returns unsubscribe |
| `isLanguageCode(v)` | Type guard for supported codes |
| `languages` / `languageList` / `defaultLanguage` / `enforced` | Registry introspection |

Exported types: `LambderLanguageMeta`, `LambderI18nConfig`, `LambderI18nInstance`, `LambderI18nTranslator`, `LambderI18nExtractParams`.
